# Mirthwood: Echoes command centre

Resolve the Echoes checkout and verify its origin is `Dwemer-Dynamics/mirthwood-echoes`. Read its AGENTS.md and [command-centre guide](../../../docs/command-centre/README.md). Inspect same-project tasks, worktrees, branch tips, open PRs and existing user authority. Maintain PROGRAMME.md, LEDGER.md and CHECKLIST.md outside the checkout using the [templates](../../../docs/command-centre/templates).

Break the batch into measurable player-facing or engineering outcomes. Use `echoes-feature-command-centre` to assign independent streams when the user asks for task chats. Record an owner for shared paths, integration and any exclusive test resource. Follow fresh handoffs and held permissions. When a worker reports a blocked merge, take its link, head and validation receipt and resolve the missing condition under the user's authority.

Verify each outcome against the changed-path run, review and actual remote state. Record the merge commit and measurements where applicable. Verify exact package, installation and gameplay separately when requested. Fast-forward a clean shared checkout, release worktrees using Git, retain needed evidence and archive completed chats under the user's storage instructions. Keep open acceptance visible.
