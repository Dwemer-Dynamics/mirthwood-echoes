# Mirthwood: Echoes command centre

Resolve the Echoes checkout and verify its origin is `Dwemer-Dynamics/mirthwood-echoes`. Read its AGENTS.md and [command-centre guide](../../../docs/command-centre/README.md). Inspect same-project tasks, worktrees, branch tips, open PRs and existing user authority. Maintain PROGRAMME.md, LEDGER.md and CHECKLIST.md outside the checkout using the [templates](../../../docs/command-centre/templates).

Break the batch into measurable player-facing or engineering outcomes. For substantial work use `echoes-feature-command-centre` to assign one separate user-visible build chat per independent outcome by default. Small status and management actions can stay with the coordinator. The coordinator owns integration, assigns shared paths and exclusive resources, and records the authority for each action. Set `model: gpt-6.2-astra` and `thinking: max` on Echoes Codex worker creation and follow-up assignments. Check the resulting dispatch or turn receipt and record actual settings when available. Keep Claude and the selected in-game dialogue model under their own settings.

Check the worker's draft, head, validation receipt, reviewer verdict and open acceptance. If a merge is blocked, record the reason and address it within the user's authority for that PR or batch.

Verify each outcome against the changed-path receipt, review and actual remote state. Record the merge commit and measurements where applicable. Track package, installation and gameplay separately. For authorised integration, fast-forward a clean shared checkout, retain evidence on E:, release clean worktrees using Git and retire verified merged branches. Check active chat and harness consumers before worktree removal. Archive completed chats under the user's storage instructions when authorised. Keep open acceptance visible.
