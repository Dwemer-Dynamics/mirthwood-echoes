# Plan an Echoes change

Read AGENTS.md, README.md, current ownership, relevant source and the fetched origin/unstable state. Trace the affected native Talk, journal, provider, launcher or installer entry point to the observable result. Follow the save, PostgreSQL and wire identities in both directions when relevant.

List the smallest complete scope, owned paths, dependencies and observable done conditions. Run `py -3 scripts/validate-change.py plan --paths <paths...>` for the proposed paths. Identify which claims need the fixture, copied-save game harness, actual provider or a visual comparison. Record missing or ambiguous evidence as unknown. Planning conveys read-only authority. Use the [worker brief](../../../docs/command-centre/templates/WORKER.md) when the plan becomes an authorised implementation.
