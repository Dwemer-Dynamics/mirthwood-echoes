# Review an Echoes change with Claude

Use a fresh Claude context independent of the author. Prefer the installed `consult-claude` project review, following its preflight and bounded read-only review procedure. Scope native reads to a clean Echoes worktree at the exact head. Supply the merge base, head, changed paths, contract, validation and PR link using the [review brief](../../../docs/command-centre/templates/CLAUDE-REVIEW.md). Inspect the response, actual model, files read and every actionable finding against the source. Record the exact reviewed head in the ledger. New commits need a fresh review. A quota, authentication or coverage failure leaves the Claude gate open. Use an alternative as the gate only when the user accepts it and name the actual reviewer.

For an authorised UI assignment use the [UI brief](../../../docs/command-centre/templates/CLAUDE-UI.md). The standard consultation tool is read-only. Apply its advice in the owner worktree, or use an explicitly authorised edit-capable context limited to the owned files. Match the appropriate in-game reference and arrange the visual and interaction checks in AGENTS.md. An author cannot independently review its own edit.
